# MedicFinder – Project Management Plan

## Overview
MedicFinder is a web-based platform designed to help users find nearby medicine availability in real time.  
This repository contains the **Project Management Plan** for MedicFinder, including charter, requirements, backlog, sprint plan, risk management, and lessons learned.

## Contents
- Project Charter
- Requirements Document
- Backlog
- Sprint Plan
- Risk & Communication Plan
- Outcome & Lessons Learned

## Tools Used
- **Notion** → Documentation
- **Trello** → Task management (Kanban board)

## Agile Workflow
- Backlog → Sprint Backlog → In Progress → Testing → Done
- Tasks broken down into **Frontend, Backend, Database, Testing**
- Managed via Trello board
